# General Chemistry

An introductory, two-semester general chemistry course covering 19 chapters — from measurement and
atomic structure through nuclear chemistry. Each chapter provides a concept map, a study guide, a
slide deck, an assessment guide, and a practice question sheet.

Authored by Yu Wang (University of Louisiana at Lafayette) with drafting assistance from an AI agent
using the [Coursewerk](https://github.com/wangyu16/orz-coursewerk) harness.
